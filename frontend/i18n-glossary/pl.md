# Polski (pl) Słownik terminologii tłumaczeń — UI sub2api

Ten słownik jest obowiązującym standardem tłumaczenia pakietów językowych frontendu sub2api. Zachowaj ścisłą spójność terminologii.

## Styl
- Neutralny tryb rozkazujący bez zaimków (standard w polskich interfejsach).
- Przyciski i etykiety zwięzłe (np. Zapisz / Anuluj / Usuń).
- Teksty można przeformułować, aby brzmiały naturalnie po polsku, bez zmiany znaczenia.

## Nie tłumaczyć (zostawić bez zmian)
Sub2API / Claude / OpenAI / Anthropic / Gemini / Grok / Codex / ChatGPT / API / JSON / WebSocket / WS / OAuth / OIDC / SSO / Redis / PostgreSQL / Docker / worker / Upstream / wartości tier (Fast / Ultrafast / Flex / Standard / Priority) / flagi konfiguracyjne (np. mode_router_v2_enabled) / identyfikatory modeli (claude-*, gpt-*, gemini-* itd.) / adresy URL / e-maile / tokeny okna czasowego (5h, 1d, 7d, 5H, 1D, 7D)
