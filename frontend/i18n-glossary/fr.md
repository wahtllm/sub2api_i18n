# Français (fr) Glossaire de traduction — UI de sub2api

Ce glossaire est la norme obligatoire pour traduire les paquets de langue du frontend de sub2api. Maintenez la terminologie strictement cohérente.

## Style
- Vouvoiement (registre « vous »), français standard.
- Boutons et libellés brefs (ex. Enregistrer / Annuler / Supprimer).
- Les textes peuvent être reformulés pour sonner naturels en français, sans changer le sens.
- Typographie française : espace avant « : ; ! ? » selon les conventions UI (utilisez une espace fine ou pas d'espace dans les libellés courts — restez cohérent avec le fichier), guillemets « … ».

## Ne pas traduire (laisser tel quel)
Sub2API / Claude / OpenAI / Anthropic / Gemini / Grok / Codex / ChatGPT / API / JSON / WebSocket / WS / OAuth / OIDC / SSO / Redis / PostgreSQL / Docker / worker / Upstream / valeurs de tier (Fast / Ultrafast / Flex / Standard / Priority) / flags de configuration (ex. mode_router_v2_enabled) / IDs de modèles (claude-*, gpt-*, gemini-*, etc.) / URLs / adresses e-mail / tokens de fenêtre de temps (5h, 1d, 7d, 5H, 1D, 7D)
