# Türkçe (tr) Çeviri Sözlüğü — sub2api Arayüzü

Bu sözlük, sub2api frontend dil paketlerinin çevirisinde bağlayıcı standarttır. Terminolojiyi titizlikle tutarlı tutun.

## Stil
- Standart Türkçe, «siz» hitabı gerekli değilse zamirsiz emir kipi.
- Düğmeler ve etiketler kısa (örn. Kaydet / İptal / Sil).
- Metinler anlamı değiştirmeden doğal Türkçe olacak şekilde yeniden ifade edilebilir.

## Çevirme (olduğu gibi bırak)
Sub2API / Claude / OpenAI / Anthropic / Gemini / Grok / Codex / ChatGPT / API / JSON / WebSocket / WS / OAuth / OIDC / SSO / Redis / PostgreSQL / Docker / worker / Upstream / tier değerleri (Fast / Ultrafast / Flex / Standard / Priority) / yapılandırma bayrakları (örn. mode_router_v2_enabled) / model kimlikleri (claude-*, gpt-*, gemini-* vb.) / URL'ler / e-postalar / zaman penceresi tokenleri (5h, 1d, 7d, 5H, 1D, 7D)
