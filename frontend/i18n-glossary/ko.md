# 한국어 (ko) 번역 용어집 — sub2api UI

이 용어집은 sub2api 프론트엔드 언어 팩 번역의 기준입니다. 용어 일관성을 위해 반드시 본 표를 따르세요.

## 문체
- 문장은 합니다체(존댓말). 버튼·라벨은 간결한 명사형(예: 저장 / 취소 / 삭제).
- 안내문은 자연스러운 한국어가 되도록 어순을 재구성해도 좋습니다(의미는 유지).
- 라벨·제목에는 문장부호(마침표)를 붙이지 않습니다.

## 번역하지 않는 표현 (그대로 유지)
Sub2API / Claude / OpenAI / Anthropic / Gemini / Grok / Codex / ChatGPT / API / JSON / WebSocket / WS / OAuth / OIDC / SSO / Redis / PostgreSQL / Docker / worker / Upstream / tier 값(Fast / Ultrafast / Flex / Standard / Priority) / 설정 플래그(mode_router_v2_enabled 등) / 모델 ID(claude-*, gpt-*, gemini-* 등) / URL / 이메일 주소 / 시간 윈도우 토큰(5h, 1d, 7d, 5H, 1D, 7D)
