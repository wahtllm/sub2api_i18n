# 繁體中文（zh-Hant，台灣用語規範）翻譯用語集 — sub2api UI

本用語集是 sub2api 前端語言包的翻譯規範。**重點：採用台灣慣用語，不是簡單的簡轉繁**（軟體/網路/設定/匯出，而非 软件/网络/设置/导出）。

## 文體
- 以 zh（簡體）為主要語義參考、en 為結構基準；產出為台灣慣用繁體。
- 標點使用全形「，、。：；」與「」引號；標籤與按鈕不加句號。
- 語氣與簡體版一致：直接、簡潔的 UI 用語。

## 不翻譯的詞（保留原文）
Sub2API / Claude / OpenAI / Anthropic / Gemini / Grok / Codex / ChatGPT / API / JSON / WebSocket / WS / OAuth / OIDC / SSO / Redis / PostgreSQL / Docker / worker / Upstream / tier 值（Fast / Ultrafast / Flex / Standard / Priority）/ 設定旗標（mode_router_v2_enabled 等）/ 模型 ID（claude-*, gpt-*, gemini-* 等）/ URL / 信箱地址 / 時間窗 token（5h, 1d, 7d, 5H, 1D, 7D）
