# Português do Brasil (pt-BR) Glossário de tradução — UI do sub2api

Este glossário é a norma obrigatória para traduzir os pacotes de idioma do frontend do sub2api. Mantenha a terminologia estritamente consistente.

## Estilo
- Tratamento informal «você», português do Brasil.
- Botões e rótulos breves (ex.: Salvar / Cancelar / Excluir).
- Os textos podem ser reformulados para soar naturais em português, sem alterar o significado.

## Não traduzir (deixar como está)
Sub2API / Claude / OpenAI / Anthropic / Gemini / Grok / Codex / ChatGPT / API / JSON / WebSocket / WS / OAuth / OIDC / SSO / Redis / PostgreSQL / Docker / worker / Upstream / valores de tier (Fast / Ultrafast / Flex / Standard / Priority) / flags de configuração (ex.: mode_router_v2_enabled) / IDs de modelos (claude-*, gpt-*, gemini-*, etc.) / URLs / e-mails / tokens de janela de tempo (5h, 1d, 7d, 5H, 1D, 7D)
