# Deutsch (de) Übersetzungsglossar — sub2api UI

Dieses Glossar ist der verbindliche Standard für die Übersetzung der sub2api-Frontend-Sprachpakete. Halte die Terminologie strikt konsistent.

## Stil
- Moderne Entwickler-Tools: informelle Anrede („du"/Imperativ), kein „Sie".
- Substantive groß schreiben (deutsche Rechtschreibung).
- Buttons/Labels kurz halten (z. B. Speichern / Abbrechen / Löschen).
- Sätze dürfen für natürliches Deutsch umgeformt werden, solange die Bedeutung identisch bleibt.

## Nicht übersetzen (unverändert lassen)
Sub2API / Claude / OpenAI / Anthropic / Gemini / Grok / Codex / ChatGPT / API / JSON / WebSocket / WS / OAuth / OIDC / SSO / Redis / PostgreSQL / Docker / worker / Upstream / Tier-Werte (Fast / Ultrafast / Flex / Standard / Priority) / Konfigurations-Flags (z. B. mode_router_v2_enabled) / Modell-IDs (claude-*, gpt-*, gemini-* usw.) / URLs / E-Mail-Adressen / Zeitfenster-Token (5h, 1d, 7d, 5H, 1D, 7D)
