# Nederlands (nl) Vertaalglossarium — sub2api UI

Dit glossarium is de bindende norm voor het vertalen van de taalpakketten van de sub2api-frontend. Houd de terminologie strikt consistent.

## Stijl
- Informeel «je/jij», standaardnederlands.
- Knoppen en labels kort (bijv. Opslaan / Annuleren / Verwijderen).
- Teksten mogen geherformuleerd worden om natuurlijk nederlands te klinken, zonder de betekenis te wijzigen.

## Niet vertalen (ongewijzigd laten)
Sub2API / Claude / OpenAI / Anthropic / Gemini / Grok / Codex / ChatGPT / API / JSON / WebSocket / WS / OAuth / OIDC / SSO / Redis / PostgreSQL / Docker / worker / Upstream / tier-waarden (Fast / Ultrafast / Flex / Standard / Priority) / configuratie-flags (bijv. mode_router_v2_enabled) / model-ID's (claude-*, gpt-*, gemini-*, enz.) / URL's / e-mailadressen / tijdvenster-tokens (5h, 1d, 7d, 5H, 1D, 7D)
