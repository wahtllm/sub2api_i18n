# Bahasa Indonesia (id) Glosarium penerjemahan — UI sub2api

Glosarium ini adalah standar wajib untuk menerjemahkan paket bahasa frontend sub2api. Pertahankan konsistensi terminologi secara ketat.

## Gaya bahasa
- Bahasa Indonesia baku, netral (tanpa kata ganti).
- Tombol dan label ringkas (mis. Simpan / Batal / Hapus).
- Teks boleh dirumuskan ulang agar terdengar natural, tanpa mengubah makna.

## Tidak diterjemahkan (biarkan apa adanya)
Sub2API / Claude / OpenAI / Anthropic / Gemini / Grok / Codex / ChatGPT / API / JSON / WebSocket / WS / OAuth / OIDC / SSO / Redis / PostgreSQL / Docker / worker / Upstream / nilai tier (Fast / Ultrafast / Flex / Standard / Priority) / flag konfigurasi (mis. mode_router_v2_enabled) / ID model (claude-*, gpt-*, gemini-*, dll.) / URL / surel / token jendela waktu (5h, 1d, 7d, 5H, 1D, 7D)
