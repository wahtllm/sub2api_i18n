# Italiano (it) Glossario di traduzione — UI di sub2api

Questo glossario è la norma obbligatoria per tradurre i pacchetti di lingua del frontend di sub2api. Mantenete la terminologia rigorosamente coerente.

## Stile
- Registro informale «tu» / imperativo, italiano standard.
- Pulsanti ed etichette brevi (es. Salva / Annulla / Elimina).
- I testi possono essere riformulati per suonare naturali in italiano, senza cambiarne il significato.

## Non tradurre (lasciare invariato)
Sub2API / Claude / OpenAI / Anthropic / Gemini / Grok / Codex / ChatGPT / API / JSON / WebSocket / WS / OAuth / OIDC / SSO / Redis / PostgreSQL / Docker / worker / Upstream / valori tier (Fast / Ultrafast / Flex / Standard / Priority) / flag di configurazione (es. mode_router_v2_enabled) / ID di modelli (claude-*, gpt-*, gemini-*, ecc.) / URL / e-mail / token di finestra temporale (5h, 1d, 7d, 5H, 1D, 7D)
