# Tiếng Việt (vi) Bảng thuật ngữ dịch — giao diện sub2api

Bảng thuật ngữ này là chuẩn bắt buộc khi dịch gói ngôn ngữ của frontend sub2api. Giữ tính nhất quán tuyệt đối của thuật ngữ.

## Văn phong
- Tiếng Việt chuẩn, trung tính (không dùng đại từ).
- Nút và nhãn ngắn gọn (vd. Lưu / Hủy / Xóa).
- Có thể diễn đạt lại câu cho tự nhiên, không thay đổi ý nghĩa.

## Không dịch (giữ nguyên)
Sub2API / Claude / OpenAI / Anthropic / Gemini / Grok / Codex / ChatGPT / API / JSON / WebSocket / WS / OAuth / OIDC / SSO / Redis / PostgreSQL / Docker / worker / Upstream / giá trị tier (Fast / Ultrafast / Flex / Standard / Priority) / cờ cấu hình (vd. mode_router_v2_enabled) / ID mô hình (claude-*, gpt-*, gemini-*, v.v.) / URL / email / token cửa sổ thời gian (5h, 1d, 7d, 5H, 1D, 7D)
