# 日本語 (ja) 翻訳用語集 — sub2api UI

この用語集は sub2api フロントエンド言語パックの翻訳規範です。訳語の一貫性を保つため、必ず本表に従ってください。

## 文体
- 文章は「です・ます」調（丁寧語）。ボタン・ラベルは簡潔な体言止め（例：保存 / キャンセル / 削除）。
- 句読点は「。」「、」。ラベル・タイトルには句点を付けない。
- 案内文は自然な日本語として読めるよう、必要なら英文の語順に固執せず再構成してよい（意味は変えない）。

## 翻訳しない語（そのまま残す）
Sub2API / Claude / OpenAI / Anthropic / Gemini / Grok / Codex / ChatGPT / API / JSON / WebSocket / WS / OAuth / OIDC / SSO / Redis / PostgreSQL / Docker / worker / Upstream（日本語文脈では「アップストリーム」も可、ファイル内で統一）/ tier 値（Fast / Ultrafast / Flex / Standard / Priority）/ 設定フラグ（mode_router_v2_enabled など）/ モデル ID（claude-*, gpt-*, gemini-* など）/ URL / メールアドレス / 時間ウィンドウトークン（5h, 1d, 7d, 5H, 1D, 7D）
