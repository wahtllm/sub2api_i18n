# Español (es) Glosario de traducción — UI de sub2api

Este glosario es la norma obligatoria para traducir los paquetes de idioma del frontend de sub2api. Mantén la terminología estrictamente consistente.

## Estilo
- Trato informal «tú», neutro para España y Latinoamérica.
- Botones y etiquetas breves (p. ej. Guardar / Cancelar / Eliminar).
- Los textos pueden reformularse para sonar naturales en español, sin cambiar el significado.
- Usa «¿…?» y «¡…!» donde corresponda.

## No traducir (dejar tal cual)
Sub2API / Claude / OpenAI / Anthropic / Gemini / Grok / Codex / ChatGPT / API / JSON / WebSocket / WS / OAuth / OIDC / SSO / Redis / PostgreSQL / Docker / worker / Upstream / valores de tier (Fast / Ultrafast / Flex / Standard / Priority) / flags de configuración (p. ej. mode_router_v2_enabled) / IDs de modelos (claude-*, gpt-*, gemini-*, etc.) / URLs / correos electrónicos / tokens de ventana de tiempo (5h, 1d, 7d, 5H, 1D, 7D)
