# 多语言维护手册（sub2api_i18n 公开 fork）

本仓库是 [Wei-Shaw/sub2api](https://github.com/Wei-Shaw/sub2api) 的公开 fork（https://github.com/wahtllm/sub2api_i18n），
在官方 en / zh 之外新增了 13 门 UI 语言：**繁體中文 (zh-Hant)、日语 (ja)、德语 (de)、韩语 (ko)、西班牙语 (es)、法语 (fr)、意大利语 (it)、荷兰语 (nl)、波兰语 (pl)、土耳其语 (tr)、印尼语 (id)、越南语 (vi)、巴西葡语 (pt-BR)**。

镜像：`ghcr.io/wahtllm/sub2api_i18n`（CI 自动构建，tag：`latest` / `0.2.8` / `sha-xxx`，amd64 + arm64）

## 支持的语言与探测逻辑

`frontend/src/i18n/index.ts`：

- 语言菜单：**System 固定第一**（跟随浏览器语言），其余按本地名 Unicode 序排列
  （Bahasa Indonesia → Deutsch → English → Español → Français → Italiano → Nederlands → Polski → Português (Brasil) → Tiếng Việt → Türkçe → 日本語 → 简体中文 → 繁體中文 → 한국어）。
- 偏好持久化在浏览器 `localStorage`（key: `sub2api_locale`）：具体语言代码或 `system`。
- 选 System 时每次加载按浏览器语言重新解析；繁体变体（zh-TW/HK/MO/Hant）优先于通用 `zh` 匹配到 zh-Hant，
  `pt-PT` 等其它葡语变体回落巴葡包，其余回落英文。
- 缺失的 key 自动回落英文（`fallbackLocale: 'en'`）。

## 文件结构

```
frontend/src/i18n/locales/{en,zh,zh-Hant,ja,de,ko,es,fr,it,nl,pl,tr,id,vi,pt-BR}/   # 15 套语言包，结构完全镜像
frontend/i18n-glossary/{zh-Hant,ja,de,ko,es,fr,it,nl,pl,tr,id,vi,pt-BR}.md          # 各语言术语表 + 文体规范（翻译必读）
frontend/src/i18n/__tests__/                           # 质量闸门（见下）
deploy/1panel/sub2api-i18n/                            # 1Panel 本地应用包
```

## 质量闸门（勿绕过）

`pnpm run build`（以及 CI 的 Docker 构建）会先跑 `check:i18n`，强制校验全部 15 种语言：

1. **key 结构与 en 完全一致**（多一个少一个都失败）；
2. 所有文案为非空字符串；
3. 代码中静态引用的每个 key 在 7 种语言里都存在；
4. 所有文案能通过 vue-i18n 消息编译（占位符 `{xxx}`、`{'{'}` 转义不被破坏）。

## 升级官方新版本的流程

```bash
git fetch upstream
# 合并稳定发布标签（例如 git merge v0.2.13 --no-ff），不要用 upstream/main
git merge v0.2.13 --no-ff
# 如 i18n/index.ts 或 __tests__ 有冲突：保留双方新增内容即可
#（新语言目录官方不存在，永远不会冲突）

cd frontend && npx pnpm@9 exec vitest run src/i18n
# 测试会精确列出 ja/de/ko/es/pt-BR 各缺了哪些 key（官方新版本会给 en/zh 加新 key）

# 按测试报错补翻译缺失的 key（对照 frontend/i18n-glossary/<lang>.md 术语表），
# 直到测试全绿，然后：

git push            # CI 自动构建新镜像（VERSION 文件变化 → 新版本 tag）
```

**v0.2.9-0.2.13 版本升级注意事项：**

- **备份重要**：升级前务必备份 PostgreSQL 数据库、`./data` 目录和 `.env` 文件
- **API Key 创建限制**：现默认启用（最多 200 个活跃 key，每小时最多创建 60 个）。如需禁用限制，在后台将两个值都设为 0
- **计费功能变更**：inflight_reservation（飞行中预留）现默认启用
- **数据库自动迁移**：`payment_orders` 表新增 `bonus_amount` 列，并添加 typesafe 支付平台（首次启动自动迁移）
- **密码重置失效**：升级后所有旧的密码重置链接将失效
- **禁止使用应用内置更新器**：不要使用应用自带的二进制更新功能，它指向官方 Wei-Shaw/sub2api 仓库，会替换掉包含自定义语言包的二进制文件。应该通过拉取新镜像版本来升级

升级 1Panel 应用：在 `deploy/1panel/sub2api-i18n/` 下新增对应版本目录（复制上一版目录，改 compose 里的镜像 tag），提交推送后服务器重新 `cp` + 同步本地应用。

## 1Panel 应用商店安装（本地应用方式）

1Panel v1/v2 均免费支持"本地应用"。在**服务器**上：

```bash
git clone --depth 1 https://github.com/wahtllm/sub2api_i18n.git /tmp/sub2api_i18n
cp -r /tmp/sub2api_i18n/deploy/1panel/sub2api-i18n /opt/1panel/resource/apps/local/
```

然后 1Panel 面板 → 应用商店 → 本地应用 → **同步本地应用**，即可看到"Sub2API 多语言版"并安装。

安装表单与官方 sub2api 应用一致（选择 1Panel 托管的 PostgreSQL / Redis 服务），差异：

- Web 端口默认 **8085**（安装时可改）
- Redis DB 固定 **5**（共享 Redis 隔离，sub2api 无全局 key 前缀，DB 编号是唯一隔离手段）
- 数据库连接池 50/10（适配 1Panel 共享 PostgreSQL 默认 max_connections=100）
- 健康检查 start_period 60s（首次安装自动初始化更稳）

`scripts/init.sh` 会在安装/升级时自动生成并固定 `JWT_SECRET`、`TOTP_ENCRYPTION_KEY` 到 `.env`
（TOTP key 不落盘、为空则 2FA 无法启用；JWT secret 只存卷内则丢卷全员掉登录——所以必须固定）。

> **镜像拉取前提**：ghcr.io 的 `sub2api_i18n` 包必须为 public。
> GitHub 无 API 可改包可见性，需在网页操作一次：https://github.com/users/wahtllm/packages/container/sub2api_i18n/settings
> → Danger Zone → Change visibility → Public（输入包名确认；公开后不可再转私有）。

## 再添加一门新语言（以 it 为例）

1. 复制 `frontend/src/i18n/locales/en/` 整目录为 `locales/it/`（`index.ts` 与 `admin/index.ts` 无需改动，相对导入自动生效）；
2. 按 `frontend/i18n-glossary/` 现有格式新建 `it.md` 术语表；
3. 翻译其余 16 个文件的字符串值（key、结构、占位符、HTML 标签、配置项名称保持原样）；
4. `frontend/src/i18n/index.ts` 扩展：`LocaleCode` 类型、`LOCALE_CODES`、`localeLoaders`、`browserLocaleMatchers`（如需浏览器自动探测），
   并把新语言按**本地名 Unicode 序**插入 `availableLocales`（System 始终第一）；
5. `frontend/src/i18n/__tests__/localeKeyCompleteness.spec.ts` 与 `localesMessageCompile.spec.ts` 各加一条 import / 一条用例；
6. `npx pnpm@9 exec vitest run src/i18n` 全绿即可。

## 已知的非 i18n 硬编码（二期项）

以下组件为 `zh ? 中文 : 英文` 的二元逻辑，新语言自动回落英文分支，功能不受影响：

- `components/common/DateRangePicker.vue`（日期格式 zh-CN / en-US）
- `views/KeyUsageView.vue`（时间窗口标签 日/D）
- `components/AliyunCaptchaWidget.vue`、`components/TencentCaptchaGate.vue`（验证码语言）
- `components/admin/AdminComplianceDialog.vue` 与 `stores/adminCompliance.ts`（合规法律文档仅有中英版本，需专业翻译后再扩展）

邮件模板按 locale 存于数据库，可在管理后台为任意语言添加；支付页语言由 `Accept-Language` 头自动透传。
